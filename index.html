❓ Device not connecting? Help & Setup ▼
1. Check Personal Hotspot:
Make sure your phone's Personal Hotspot named BMS (password: bms.local) is turned ON and car ignition is ON.
2. Auto-Sync via Device Wi-Fi:
If the IP address changed:
• Connect your phone's Wi-Fi to network BMS_Setup (password: bms.local).
• Tap «📡 Auto-Sync via BMS_Setup» button above.
The controller will link the new IP address and switch back to mobile network automatically.
3. Manual IP Entry:
In your phone's settings (Personal Hotspot ➔ Connected Devices), find the IP address of the controller and enter it manually.
